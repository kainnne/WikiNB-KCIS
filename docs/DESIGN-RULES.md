# Kain³e 介面設計規則（粉紫玻璃）

2026-11-24 起，kcis.kainnne.com、ai-tools.kcis.kainnne.com、wikinb.kcis.kainnne.com 與 AI-901 練習都照這份規則。基準是 kainnne.com 的玻璃字卡。改介面前先讀完；不確定時照 kainnne.com 現場做。

## 不能動的
- 文字、功能、流程、資料、API、登入與權限一律不變。美化只改外觀與互動回饋。
- 康橋校徽照用，不重畫、不改色。
- 不加光暈、外發光、螢光、殘影、擴散光圈、霓虹邊。按鈕只留本身的材質與光影。
- 不加幼兒語氣、不把中文字放大來「照顧學生」。

## 色彩
| 用途 | 值 |
|---|---|
| 主文字 | `#2e0f38` |
| 次文字 | `#5b3b66` |
| 輔助文字 | `#8d7395` |
| 紙底 | `#fbf2f6`（可加一層很淡的粉紫徑向漸層） |
| 康橋紫（校徽主色）：KCIS 標記、選中／目前所在狀態、重要數字 | `#900080` |
| 康橋青（校徽副色）：少量點綴，例如成功狀態、次要標籤、一種玻璃色調；一個畫面不超過一兩處 | `#0098a0` |
| 強調：玫瑰 / 紫 / 梅 | `#c8306b` / `#6a46c8` / `#7b2f8f` |
| 玻璃色調（卡片左上 145° 漸層，44% 處透明） | 玫瑰 `rgba(255,128,178,.2)`、紫 `rgba(150,120,255,.2)`、粉紫 `rgba(240,150,210,.18)`、康橋紫 `rgba(144,0,128,.14)`、康橋青 `rgba(0,152,160,.14)` |
風格是「Kain³e 粉紫玻璃 × 康橋校徽色」：底是粉紫玻璃，康橋紫與康橋青是識別色。不再使用深藍漸層、藍色格線、藍色光球；青色只作點綴，不當主色。

## 玻璃材質
- 卡片：`background: linear-gradient(145deg, <色調>, transparent 44%), rgba(255,255,255,.5)`；`backdrop-filter: blur(25px) saturate(1.25)`；`border: 1px solid rgba(255,255,255,.8)`；`box-shadow: 0 26px 80px rgba(200,48,107,.13), inset 0 1px rgba(255,255,255,.55)`。
- 深色玻璃（一頁最多一兩處重點）：`linear-gradient(145deg, rgba(255,140,200,.3), transparent 52%), rgba(64,22,88,.6)`，白字，邊框 `rgba(255,255,255,.38)`。
- 頁首：白 50% 玻璃，同樣的 blur。
- 圓角：大卡 32px、面板 24px、輸入框與小卡 16px、按鈕與標籤 999px。
- 卡片可加跟隨游標的反光：`radial-gradient(220px circle at var(--mx) var(--my), rgba(255,255,255,.58), transparent 72%)`，hover 或按住時出現。這是材質反光，不是光暈。

## 按鈕與控制項
- 主要按鈕：粉色膠囊 `linear-gradient(180deg,#ffd0e2,#f7a8c8)`，字 `#5a1a40`，`box-shadow: inset 0 1px rgba(255,255,255,.7), inset 0 -2px rgba(190,60,120,.18), 0 8px 18px -10px rgba(200,48,107,.55)`。hover 上移 1px；按下下移 1px，陰影改成內凹。
- 次要按鈕：白色玻璃膠囊，字 `#2e0f38`，邊框 `rgba(255,255,255,.8)`。
- 文字連結：底線從 0 畫到 100%。
- 輸入框：白 70% 玻璃，`1px solid rgba(46,15,56,.14)`，圓角 16px；focus 用 `2px solid rgba(123,63,191,.7)` 外框、offset 2px，不用發光陰影。
- 切換鈕（語言、分頁）：玻璃底＋白色滑塊，滑塊用 transform 滑動。
- 觸控：hover 會出現的回饋，按住時也要出現（`.pressed` 或 `:active`）；點擊區至少 40px 高。

## 字體
- 標題、大數字、英文品牌字：Comfortaa 700。
- 內文：Nunito + Noto Sans TC（或 PingFang TC），600–800 粗細。
- 標籤、編號、eyebrow：DM Mono，大寫、字距 .12–.22em、10.5–12px。
- 中文介面字維持原本大小，不為了學生放大。

## 動態
- 緩動：`cubic-bezier(.16,1,.3,1)`。卡片 hover 上移 2–4px，不放大、不傾斜。
- 進場：淡入加上移 16px，0.8–1.1 秒，依序延遲；卡片可「飛入」（從下方、稍微後傾）。
- `prefers-reduced-motion` 時全部靜止，內容不能因此看不到。
- 不能因為求快而拿掉效果；動畫只用 transform 與 opacity，背景繪圖晚於內容載入。

## 背景
- kcis.kainnne.com 與 ai-tools 首頁：校園手繪本（共用的 sketchbook 模組，兩站元素畫法不同）。
- 其他內頁：紙底 `#fbf2f6`＋淡粉紫徑向漸層；ai-tools 在工具流程中手繪本淡到 30%。
- 不用格線、光球、粒子。

## RWD 檢查
每次改完至少看：390×844、375×667、844×390（手機橫式）、820×1180（平板）、1440×900。不能有橫向捲動、文字不能被蓋住、按鈕在第一屏可按。

## 備份與發布
- 大改前先打 git tag：`backup-YYYYMMDD-<主題>`，推到遠端。
- 改完用瀏覽器實際看過各尺寸再發布；GitHub Pages 建置失敗（例如字型下載逾時）先重跑，不要硬改無關程式。
